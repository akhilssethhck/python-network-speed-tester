# Security Policy

## Supported Versions

This project is currently maintained on the latest version available in the `main` branch.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately through GitHub rather than publicly disclosing it.

When reporting a vulnerability, please include:

- A description of the issue
- Steps to reproduce the issue
- Potential security impact
- Any relevant screenshots or logs

Please do not include passwords, API keys, tokens, or other sensitive information in an issue or pull request.

## Responsible Use

This tool is intended for network performance testing on systems and networks that you own or have explicit permission to test.

The author is not responsible for misuse of this software.
